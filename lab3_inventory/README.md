# Inventory Manager (SEN 401 - Lab 3: Status Accounting & Auditing)

Tracks items in stock and calculates the total stock value.

## Files
| File | Purpose |
|------|---------|
| `inventory.py` | Data: list of items (`item_name`, `quantity`, `price`) |
| `app.py` | Reads the inventory and calculates total stock value |
| `utils/helpers.py` | `highest_stock_item()`, `lowest_stock_item()` |
| `requirements.txt` | Python dependencies |

## Run
```bash
python app.py
```
